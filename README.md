# AIREN LP（デザインラフ用モック）

`html.to.design` でURLインポートする前提で作っています。
**インポート時のビューポート幅は 390px（または 375px）** を指定してください。

## デザイン方針

- **配色**：ベースは白。`白 → 極薄ティント → 締めの濃色 → アクセント` の4層で、アクセント（サラのピンク）は面で塗らず、文字・線・ボタンなど小さく使う。参考：Awarefy。
  - ベース `#FFFFFF` ／ ティント `#EFF2F9`（交互セクション）・`#FBEDF2`（CTA帯）
  - 締めの濃色 `#16203A` インディゴ ― **最終CTAとフッターだけ**に使い、「夜の静けさ」はここで表現
  - アクセント サラピンク `#C9436F`（文字・ボタン）／`#E86C96`（装飾）
  - サブ ブルーラベンダー `#5B6798`（文字）／`#8E9BCB`（装飾）
  - テキスト `#26293A` ／ 本文 `#5A6070`
- **CTAの考え方**：白地の中でボタンだけが濃いローズ。彩度の高い面で埋めず、「煽らない」トーンを保つ。
- **可読性ルール**（参考：aishift.com）：セクション見出し・リードは中央揃えで、**意味のかたまりで手動改行**して1行を短く保つ。本文15px／行間1.9／字送り0.02em。見出しは行間1.45でジャンプ率を上げる。セクション余白78px。
- **サラの吹き出し**（`.sara-pop`）：要所4箇所（共感／記憶／料金／安全性のあと）にサラのアイコン＋吹き出しを配置。左右交互。**Figmaインポート用に「出現後の静止状態」で書いてある**ので、実装時はスクロール連動でふわっと出す想定。
- **レイアウト**：**スマホ縦型固定（1カラム・最大420px）**。PCでも横に広がらず、縦型カラムを中央に置いたまま表示します（要件「縦型＝スマホ最適化デザインを採用」に合わせた設計）。
- **フォント**：Zen Maru Gothic（見出し）／ Noto Sans JP（本文）／ Outfit（英字・数字）。すべてGoogle FontsなのでFigmaでも使用可。
- Figmaインポートの都合上、登場アニメーション・`position:sticky`・`clip-path`・`backdrop-filter` は不使用（追従CTAのみ `position:fixed`）。

## 画像について

`images/` はすべて **SVGのプレースホルダー** です。3Dアニメ調の本番素材に差し替えてください。

- `sara-hero.svg` … FVメインビジュアル（縦 3:4）
- `sara-portrait.svg` … サラのポートレート（1:1）
- `sara-sub-01〜03.svg` … 表情カット（3:4）
- `demo-video.svg` … 会話デモ動画／GIFのサムネイル（縦型）
- `scene-*.svg` … 利用シーン4点（1:1）
- `og.svg` … OGP（1200×630）
